# Repository Instructions

## TransCrab Delivery Policy

- For every explicit TransCrab request in this repository, complete the configured workflow end to end: prepare, translate, refine when required, verify, commit, deliver through the repository's existing production flow, deploy, and confirm the public article returns HTTP 200.
- The authorized production branch is `main`, which deploys through the repository's existing GitHub Pages workflow.
- Stage and commit only the new article directory and changes explicitly requested for that run. Never force-push.
- Ask for confirmation before changing credentials, Git remotes, the production branch, or deployment settings.
